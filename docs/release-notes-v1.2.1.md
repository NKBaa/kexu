# 课序 v1.2.1

课表新增分享按钮，支持导出日历文件与 JSON 文件。

## 新增功能

- 课表顶栏新增「分享」按钮，点击后选择：
  - **分享日历文件（.ics）**：把每次课按实际日期展开成日历事件，含课程名、时间、教室、教师与节次；可直接导入手机/电脑日历。
    - 节假日当天的课不会写入；
    - 支持多套作息，按每天生效的作息换算起止时间；
    - 每个事件有稳定 UID，重复导入不会产生大量重复事件。
  - **分享 JSON 文件**：完整课表数据（学期、课程、时段、作息），可备份或再次导入。
- 生成后调用系统分享面板，可发送到微信、邮件、网盘或保存到文件。
- 分享文件生成在临时目录，不污染课表数据目录。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.1-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.1.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。
