# 课序 v1.1.29

课程卡片与课程详情里显示对应作息时间。

## 更新内容

- 课表里的**课程卡片**新增该时段的作息时间：
  - 正常宽度显示完整范围，如 `08:00-09:40`；
  - 手机一屏 7 天的窄卡片只显示开始时间，避免被省略；
  - 时间放在教师下方，空间不足时优先保留，教室等信息仍按原优先级降级。
- 点开课程详情的「节次」一行也会追加时间，如 `第 1-2 节 · 08:00-09:40`。
- 时间取自当前周生效的作息方案，夏季/冬季作息切换后自动对应。
- 新增 CourseCard 时间显示测试；测试 572 用例（566 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.29+31（Android versionCode 31）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.29-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.29.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
