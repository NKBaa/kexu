# 课序 v1.2.10

参考移动端课表重排顶部：大号周次 + 日期，操作收进右侧。

## 更新内容

- 顶栏改为参考布局：
  - 左侧大号「第 N 周（本周 / 学期结束）」；
  - 下方显示当天日期 `yyyy/M/d`；
  - 点标题打开周次选择，也可以左右滑动课表切换。
- 右侧操作：添加 / 撤销 / 重做 / 更多。
  - 「更多」包含：分享课表、导入 / 导出数据、上一周、下一周、回到本周。
- 撤销/重做仍为 Word 式，不再弹出修改历史列表。
- 测试保持 667 用例（661 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.10+66（Android versionCode 66）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.10-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.10.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
