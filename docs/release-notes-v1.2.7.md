# 课序 v1.2.7

重排课表顶栏，并把回退改成 Word 式撤销/重做；首次向导增加节假日步骤。

## 更新内容

- **课表顶栏分两行**：
  - 第一行：学期名 + 撤销 / 重做 / 分享 / 添加；
  - 第二行：`‹ 第 N 周 ›` 与「本周」，周次切换不再挤在右上角；
  - 添加按钮改为紧凑图标按钮，避免顶栏过挤。
- **Word 式撤销/重做**：
  - 顶栏直接点撤销/重做，不再弹出「修改历史」列表；
  - 新的编辑会截断重做时间线；
  - 没有可撤销/重做内容时按钮自动禁用；
  - 撤销/重做结果用 SnackBar 提示。
- **首次使用向导增加节假日步骤**：
  - 共 4 步：学校作息 → 大模型 API → 节假日 → 添加课程；
  - AI 步骤新增「跳过 AI 设置，稍后再配」按钮；
  - 节假日步骤可直接添加/管理，也可以跳过。
- 测试 662 用例（656 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.7+63（Android versionCode 63）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.7-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.7.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
