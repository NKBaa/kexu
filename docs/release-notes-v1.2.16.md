# 课序 v1.2.16

新增主题中心与 GitHub 主题市场，支持用 JSON 代码自己写主题。

## 更新内容

- 「设置 → 主题中心」：
  - 主题模式：跟随系统 / 浅色 / 深色；
  - 内置主题：暖白、午夜蓝、樱花、森林、高对比，点击立即应用；
  - 我的主题：新建、编辑、删除、应用；
  - 主题市场：从 GitHub `templates/themes.json` 拉取，安装到本地；
  - 显示周末开关也移到这里。
- **自己写主题**：
  - 新建主题打开代码编辑器，用 JSON 描述浅色/深色色板与圆角；
  - 支持预览、保存并应用；
  - 主题 id 不能与内置主题冲突。
- 主题应用会实时切换整个 App 的色板、卡片、输入框、导航栏与圆角。
- 自定义主题与当前主题保存在 `settings.json`。
- 删除无用代码：移除已不再使用的历史列表接口与旧可用性 Provider。
- 测试 678 用例（672 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.16+72（Android versionCode 72）。

## 主题市场维护

主题市场文件为仓库 `templates/themes.json`；新增主题后提交 `main`，
用户在主题中心点刷新即可看到，不需要发新版。字段说明见 `templates/README.md`。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.16-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.16.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
