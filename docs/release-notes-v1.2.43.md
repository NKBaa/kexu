# 课序 v1.2.43

完善 ColorOS 16 日历抽屉的跟手滑动效果。

## 更新内容

- **月历抽屉跟手滑动**：
  - 上下拖动月历时，日历高度实时跟随手指，不再只在松手后跳变；
  - 松手后根据拖动距离和速度吸附到「整月」或「单周」；
  - 日历底部新增 ColorOS 风格的拖动把手，可直接按住上下拖动；
  - 点把手也能在整月 / 单周之间切换。
- **单周视图**：
  - 收起后只保留当前选中日期所在的一周；
  - 周视图下方显示相对天数、公历与农历日期，以及「今日安排」；
  - 仍可左右滑动切换月份。
- 课表空状态文案修正为「更多 → 添加课程」。
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.43+99（Android versionCode 99）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.43-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.43.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
