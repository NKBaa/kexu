# 课序 v1.1.43

「添加」与「AI」位置互换，AI 助手支持上传图片。

## 更新内容

- 右下角悬浮按钮改为 **AI 助手**：
  - 点开可一句话改课表；
  - 输入框旁新增「上传课表图片」按钮，直接进入图片转课表。
- 「添加」移到课表页顶栏：
  - 手动添加课程、图片转课表仍在添加面板中；
  - 不再占用右下角悬浮按钮。
- 空课表引导、使用向导和 README 同步更新入口位置。
- 新增 AI 悬浮入口与上传图片按钮测试；测试 584 用例（578 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.43+45（Android versionCode 45）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.43-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.43.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
