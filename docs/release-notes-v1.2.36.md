# 课序 v1.2.36

修复 Android 签名冲突：改用固定的发布签名密钥。

## 为什么会出现签名冲突

之前所有 APK 都用本机自动生成的 Android Debug 签名。Debug keystore 一旦被系统重建，
新 APK 的签名就和已安装版本不一致，Android 会拒绝覆盖安装并提示「签名冲突」。

## 本次修复

- 新增固定发布签名配置：
  - `app/android/key.properties` 指向本机固定 keystore；
  - `release` 构建优先使用该签名；
  - 以后版本都用同一把密钥，覆盖安装不再冲突。
- 签名文件与密码不进入 Git（`key.properties`、`*.jks` 已被忽略）。
- 版本 1.2.36+92（Android versionCode 92）。

## 从旧版本升级（重要）

由于旧 APK 使用的是**已经丢失的旧 debug 密钥**，无法直接覆盖安装。需要一次性处理：

1. 打开旧版课序，在「设置 → 数据管理」导出 JSON 备份（如果有数据）；
2. 卸载旧版课序；
3. 安装 `kexu-v1.2.36.apk`；
4. 如需恢复数据，在「设置 → 数据管理」导入刚才的 JSON。

从此以后，v1.2.36 及后续版本签名一致，可以正常覆盖更新。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.36-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.36.apk` 传到手机安装（固定发布签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
