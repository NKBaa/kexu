# 课序 v1.2.46

日历收缩改为与手指滚动距离联动，不再只判断划动方向。

## 更新内容

- 日历高度直接映射日程列表的滚动距离：
  - 列表在顶部时显示整月；
  - 向下滚动时日历按比例连续收缩；
  - 滚动到约 160px 时收缩为单周；
  - 向上滚回顶部时按比例展开。
- 不再用「方向 + 阈值」瞬间切换，减少过于灵敏、突然跳变和回弹；
- 手动拖动把手仍可跟手调整；手动切换后会同步列表滚动位置，避免下一次滚动把日历拉回；
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.46+102（Android versionCode 102）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.46-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.46.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
