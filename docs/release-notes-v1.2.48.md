# 课序 v1.2.48

课程拖动按钮改为长按后才能拖动，减少滑动课表时的误操作。

## 更新内容

- 长按课程右下角的拖动柄约 500 毫秒后，可以调整课程的星期和节次。
- 短按拖动柄或立即拖动不会移动课程；课程正文仍支持点击查看详情、长按编辑。
- 保留拖动预览、跨星期移动和课程跨节数。
- 更新新手引导和课程拖动提示。
- 补充短按、提前移动、长按拖动及跨星期拖动的回归测试。

版本：1.2.48+104（Android versionCode 104）。

## 构建产物命名

- Android：`kexu-v1.2.48.apk`，沿用固定发布签名。
- Windows：`kexu-v1.2.48-windows.zip`，解压后运行 `course_timetable.exe`。
