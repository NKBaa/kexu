# 课序 v1.2.0

新增 Android 桌面小组件、节假日管理与上课提醒通知。

## 新增功能

### 桌面小组件「今日课表」
- Android 桌面长按 → 小组件 → 选择「课序 / 今日课表」添加；
- 显示日期、星期、教学周、今天课程与教室；
- 有节假日时显示节日名称，当前正在上的课高亮；
- 点击小组件直接打开 App；
- 原生只读快照渲染，不依赖 App 常驻后台；课表或节假日改动后打开 App 会立即同步；
- 快照不是今天时显示「打开课序查看今日课程」，避免展示过期课程。

### 节假日管理
- `设置 → 节假日与提醒` 可添加/删除放假日期；
- 节假日当天课表显示「节假日」、不显示课程；
- 上课提醒自动跳过节假日；
- 节假日会同步到桌面小组件。

### 上课提醒
- 开启后按未来 7 天课表排系统闹钟，上课前 5/10/15/30 分钟发通知；
- 不需要 App 常驻后台；
- Android 13+ 请求通知权限；Android 12+ 未授予精确闹钟权限时自动降级为不精确闹钟；
- 支持开机、App 更新、时区/时间变化后恢复排程。

### OPPO / vivo 等厂商活动卡片（实验）
- 通知样式可选「系统通知」或「厂商活动卡片（实验）」；
- 后者使用独立高优先级渠道「课序活动提醒」，设置 `category=event`，
  尽量争取 OPPO / vivo / 小米等系统的横幅/卡片展示；
- **是否真的渲染成厂商活动卡片由系统通知策略决定，App 无法保证**；
- 国产 ROM 还可能需要手动开启自启动、后台运行、横幅通知、锁屏通知，
  设置页提供「打开系统通知设置」入口。

## 其他
- 新增 `设置 → 桌面小组件`：添加步骤与「立即刷新小组件」按钮；
- 新增 `设置 → 节假日与提醒`：节假日、提醒开关、提前分钟、通知样式、通知权限；
- 课表周视图对节假日列显示「节假日」，宽屏当日课程栏显示节日名称；
- 测试 646 用例（640 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.0+56（Android versionCode 56）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.0-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.0.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
