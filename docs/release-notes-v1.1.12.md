# 课序 v1.1.12

在 v1.1.11 的「学期与作息」排版优化基础上做最后一处细节打磨。

## 更新内容

### 学期与作息页面
- 「按今天快速定位学期」卡片里的说明改为**两行显示**：
  `今天：2026-11-02` / `把今天算作第 N 周，即可反推第 1 周周一。`
  避免中文在窄屏上断成「第 1 周周 / 一。」这种不自然的换行。
- 其余排版保持 v1.1.11：三个字段整行排列、常用周数 Chip 独立一行、
  定位卡片独立浅色块、作息方案头部两行摘要 + 右对齐「新增方案」。

### 其他
- 版本 1.1.12+14（Android versionCode 14）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.12-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.12.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
