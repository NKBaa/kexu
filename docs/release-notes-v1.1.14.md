# 课序 v1.1.14

本次按反馈精简设置页：删除常用周数快捷 Chip、缩小 CottonAPI 推荐条，并把所有常驻说明文字改为「灰色感叹号 + 点击查看」。

## 更新内容

### 学期与作息
- **删除「常用周数」快捷 Chip**（12 / 14 / 16 / 18 / 20 周），总周数直接手动输入即可。
- 日期、总周数的 helper 文字删除，改为输入框右侧的**灰色感叹号**图标；
  点击弹窗查看「点击选择日期 / 常见 16~20 周」等说明。
- 「按今天快速定位学期」的常驻说明文字删除，改为标题右侧灰色感叹号，点击查看。
- 「作息方案」的说明文字删除，改为标题旁灰色感叹号；只有一套方案时的提示也合并进该弹窗。
- 页面顶部副标题说明改为标题栏右侧灰色感叹号。

### 大模型配置
- **CottonAPI 推荐条缩小**为单行紧凑样式：图标 + 「推荐使用 CottonAPI」+ 灰色感叹号 + 「打开官网」。
- 详细推荐说明收进灰色感叹号弹窗，不再占据大块页面。
- 「温度」「超时」的建议文字改为标签旁灰色感叹号。

### 其他设置页
- 更新页底部说明、关于页的建模说明与快捷键说明、作息方案底部提示等常驻文字，
  统一改为标题/卡片旁的灰色感叹号，点击弹窗查看。
- 设置二级页（AI、数据、同步、更新、外观、关于等）的顶部副标题也统一改为标题栏灰色感叹号。

### 其他
- 版本 1.1.14+16（Android versionCode 16）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.14-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.14.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
