# 课序 v1.1.0

首个公开版本：面向大学生**不规律课表**的 Flutter 课表 App（Android + Windows），
支持大模型图片转课表、对话式一句话改课表与 GitHub Releases 在线更新。

## 新增

### 对话式「一句话改课表」
- 每次请求自动注入**当前时间上下文**：当前日期时间、当前教学周、本周每天日期、
  下一教学周，以及当天生效作息（上午 / 下午 / 晚上各是第几节）。
  「今天 / 明天 / 下周三 / 下午的课」会被换算成 `dayOfWeek + 显式周次`。
- 容忍**白话、简称、错别字与不精确描述**（高数 → 高等数学、线代 → 线性代数），
  模型输出后本地还会用课程名模糊匹配再校验，唯一命中才改写。
- 支持 **AI 反问澄清**：缺少「改哪门课 / 改成什么」时先追问，并给出可直接点选的候选。
- 支持**多轮对话**：追问与回答在同一对话里继续，历史作为独立消息带给模型。
- 保留安全流程：先出方案 → 逐条勾选 → 应用 → 执行报告。

### 图片转课表支持多图
- 一次可选多张（最多 9 张，支持分次追加），按每次请求最多 4 张分批识别。
- 跨图合并同名课程；同一时段**周次取并集**（单周截图 + 双周截图可拼成完整周次）；
  多图重叠自动去重；某一批失败不影响其余批次，并单独提示。
- 仍然保留草稿核对，确认后才写入课表。

### 在线更新（GitHub Releases）
- 设置 → 检查更新：填 `owner/repo` 后检查最新 Release，展示版本、更新时间、说明与包大小。
- 国内镜像加速：自动 / 直连 / ghfast.top / ghproxy.net / gh-proxy.com / 自定义前缀。
  检查更新会优先使用能代理 GitHub API 的镜像，下载按所选镜像回退。
- Windows 下载后启动安装包或打开目录；Android 下载 APK 后调起系统安装（失败回退浏览器）。
- 启动时静默自动检查（可关闭），发现新版本用底部提示条轻提示。

## 改进与修复
- 修复 Windows 构建：清理旧路径 CMake 缓存、`main.cpp` 非 ASCII 注释导致的 C4819 编译错误。
- 清理无用公开 API（单图入口、未使用的 getter/工具方法等），补充对应测试。
- tooling 脚本改为按脚本位置推导路径，移动项目目录后不再失效。
- 新增 `tooling/build-all.ps1`（按 pubspec 版本归档到 `dist/`）与
  `tooling/release.ps1`（gh 一键发布），发布流程见 `docs/release.md`。

## 安装
- **Windows**：下载 `kexu-v1.1.0-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.0.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新
在「设置 → 检查更新」里填写本仓库 `NKBaa/kexu`，之后即可检测到本版本及后续更新。
