# 课序 v1.2.21

优化长按新建课程的过渡，并放慢 AI 渐变扩散速度。

## 更新内容

- 长按课表空白处新增课程：
  - 增加轻触觉反馈；
  - 新增课程页改为淡入 + 轻微上滑过渡，不再瞬间跳出；
  - 返回时同样平滑收起；
- AI 悬浮按钮的渐变扩散动画：
  - 从 560ms 放慢到 900ms；
  - 曲线改为更柔和的减速，扩散过程更明显；
- 测试 686 用例（680 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.21+77（Android versionCode 77）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.21-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.21.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
