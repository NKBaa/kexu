# 课序 v1.2.25

修复回看教程时第一步一直加载的问题。

## 更新内容

- 回看教程（更多 → 重启教程）不再请求 GitHub 学校模板：
  - 第一步直接展示学期、作息、节假日的图文说明；
  - 网络慢或离线时也能正常翻页，不会卡在加载圈。
- 首次向导的学校模板加载页增加提示：
  - 一直加载不出来时，可以直接点「下一步」继续；
  - 之后仍可在「学期与作息」里手动设置。
- 测试 690 用例（684 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.25+81（Android versionCode 81）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.25-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.25.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
