- **Windows**：下载 `kexu-v1.1.42-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.42.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。
