# 课序 v1.1.39

改进模型选择菜单：从简陋的长下拉改为可搜索的圆角弹层。

## 更新内容

- 模型选择改为**底部弹层**：
  - 顶部显示模型总数；
  - 带搜索框，可按模型名实时过滤；
  - 模型以圆角卡片列表展示，每项显示模型名与选中状态；
  - 当前已选模型显示勾选标记。
- 原「获取模型列表」按钮和自动获取逻辑保持不变。
- 选择模型后自动回填并关闭弹层。
- 版本 1.1.39+41（Android versionCode 41）。
- 测试保持 581 用例（575 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.39-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.39.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
