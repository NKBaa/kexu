# 课序 v1.1.8

本次更新优化课表网格交互：**长按课程编辑信息**、**拖动课程调整节次**。

## 更新内容

### 长按编辑课程
- 在周课表中**长按**任意课程卡片，直接打开课程编辑页，
  可修改课程名、教师、课程号、学分、备注、颜色与各上课时段。
- 点击卡片仍然是查看详情（不改变原有习惯）。

### 拖动调整节次
- **拖动**课程卡片到本列其他位置，即可调整这门课占用的节次：
  - 保持原来的**跨节数**不变（例如 1-2 节拖到第 5 节 → 5-6 节）；
  - 星期保持不变（拖到别的列不会生效，避免误改）；
  - 拖出上下边界时自动贴边（1 节 / 最后一节）；
  - 拖动时整列高亮提示可放置，松手后底部提示「已把「课程」调整到第 X-Y 节」。
- 调整会自动记入「修改历史」，可随时回退。

### 其他
- 版本 1.1.8+10（Android versionCode 10）。
- 测试增至 557 个用例（551 通过 / 6 默认跳过），新增长按回调与拖动节次换算测试。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.8-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.8.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
