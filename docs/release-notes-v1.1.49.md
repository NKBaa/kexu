# 课序 v1.1.49

批量操作页的筛选控件移到搜索框同一行，并与「取消筛选」合并。

## 更新内容

- 「全部星期」「全部周次」筛选胶囊移动到搜索框右侧；
- 原来单独的筛选行移除；
- 「取消筛选」按钮紧跟在筛选项后面，可一次清除搜索词和两个筛选；
- 窄屏下筛选项自动收缩为「星期」「周次」，避免换行或横向溢出；
- 同时修复窄屏下底部统计栏的横向溢出。
- 版本 1.1.49+51（Android versionCode 51）。
- 测试 588 用例（582 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.49-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.49.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
