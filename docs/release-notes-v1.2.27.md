# 课序 v1.2.27

修复重复课程重新导入选择「覆盖已有」后仍出现两门课程的问题。

## 更新内容

- 导入前先合并同名课程：
  - 同一次识别结果里出现同名课程时，只保留一门，时段取并集；
  - 覆盖导入时按归一化课程名移除所有旧课程，再写入合并后的新课程。
- 课程名归一化更宽容：
  - 忽略空格、大小写、零宽字符；
  - 全角括号与半角括号视为同一门课，避免因「（上）」和「(上)」留下两门。
- 新增回归测试覆盖「同名合并」与「覆盖导入只保留一门」。
- 测试 692 用例（686 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.27+83（Android versionCode 83）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.27-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.27.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
