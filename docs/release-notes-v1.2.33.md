# 课序 v1.2.33

移除覆盖在界面上的交互教程，恢复简洁的图文教程。

## 更新内容

- 删除交互教程的聚光灯高亮层、自动启动逻辑和 `showcaseview` 依赖；
- 课表「更多 → 使用教程」恢复为打开 5 步图文教程：
  - 学校作息；
  - 大模型；
  - 节假日；
  - 添加课程方式；
  - 课表编辑与新增。
- 首次向导完成后不再自动弹出教程，避免打扰；
- 其他界面与功能不变；
- 测试 697 用例（691 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.33+89（Android versionCode 89）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.33-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.33.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
