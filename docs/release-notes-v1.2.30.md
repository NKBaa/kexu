# 课序 v1.2.30

日程改为独立月历，用于记录考试、作业截止、活动等事项，并支持 AI 设置。

## 更新内容

- 「日程」页改为月历：
  - 月历上用圆点标出有日程的日期；
  - 点日期查看当天事项；
  - 支持上个月 / 下个月 / 回到今天；
- 日程事项与课表无关，可记录：
  - 考试、作业截止、社团活动、会议等；
  - 全天事项，或指定开始/结束时间；
  - 备注（地点、要带的东西等）。
- 手动新建 / 编辑 / 删除日程；
- **AI 设置日程**：
  - 右上角「AI」输入一句话，例如「下周三下午 3 点交高数作业」；
  - 模型解析出日期、时间、标题与备注；
  - 先预览，再确认添加；
  - 需要先在「设置 → 大模型配置 → 语言模型」里配置语言模型。
- 日程保存在独立的 `schedule_events.json`，不写入课表，也不影响课表同步。
- 测试 697 用例（691 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.30+86（Android versionCode 86）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.30-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.30.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
