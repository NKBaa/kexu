# 课序 v1.1.5

本次更新新增「自动获取模型列表」：配置大模型时不用再手填模型名，直接从服务端拉取候选。

## 更新内容

### 大模型配置：自动获取模型列表
- 模型名输入框右侧新增「获取模型列表」按钮：请求 `GET {baseUrl}/models`，
  自动列出服务端可用模型（去重、排序），点「选择模型（已获取 N 个）」即可挑选。
- **打开配置页时静默预取**：已填好 baseUrl 与 API Key 时自动拉一次，不弹打扰；
  失败不打断操作，仍可手动点按钮重试。
- 兼容多种返回格式：`{"data":[{"id":...}]}`、`{"models":[...]}`、`{"result":[...]}`
  以及字符串数组；`baseUrl` 误粘完整 `/chat/completions` 地址时会自动纠正为 `/models`。
- 服务端不支持 `/models`（如部分本地服务）时给出中文提示，继续手填模型名即可。
- 每套模型配置（视觉 / 文本）独立获取、独立选择。

### 其他
- 版本 1.1.5+7（Android versionCode 7）。
- 测试增至 539 个用例（533 通过 / 6 默认跳过），新增模型列表解析与配置页交互测试。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.5-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.5.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
