# 课序 v1.1.3

在 v1.1.2（圆润界面 + 作息修改）基础上修复并增强作息平移：**「上午/下午/晚上的课」只会平移对应节次范围**，不会把全天作息一起挪。

## 更新内容

### 作息平移支持节次范围（修复）
- 「下午的课整体推迟 10 分钟」：AI 会按当天作息把「下午」换算成节次范围（如第 5-8 节），
  只平移这几节，上午/晚上保持不变；`shiftSchedule` 新增可选 `fromPeriod` / `toPeriod`。
- 支持「所有课/整套作息」整体平移（省略范围）与「第 9 节及以后」这类半开范围；
  范围不合法、范围内没有节次、平移跨过 00:00 都会跳过并说明原因。
- 提示词同步更新：明确「上午/下午/晚上 → 节次范围」的换算规则，避免模型把所有节次一起平移。

### 界面（v1.1.2 起）
- 卡片/弹窗 16px 圆角；按钮、输入框、Chip 统一胶囊圆角；底部弹层与提示条同步圆润。
- 一句话改课表输入区：发送键与输入框垂直居中对齐；示例新增作息指令。

### 其他
- 版本 1.1.3+5（Android versionCode 5）。
- 测试增至 529 个用例（523 通过 / 6 默认跳过）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.3-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.3.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
