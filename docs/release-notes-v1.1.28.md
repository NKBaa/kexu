# 课序 v1.1.28

课程编辑的节次选择中显示对应作息时间。

## 更新内容

- 「开始节 / 结束节」下拉菜单的每个节次项显示该节作息，例如：
  - `第 1 节 08:00-08:45`
  - `第 2 节 08:55-09:40`
- 输入框收起时仍显示紧凑的「第 N 节」，不占额外宽度；展开菜单可看到完整时间。
- 时段摘要里的时间改为显示完整范围（如 `第 1-2 节 08:00-09:40`），不再只显示起始节的时间。
- 新增测试覆盖节次下拉的作息时间展示；测试 571 用例（565 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.28+30（Android versionCode 30）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.28-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.28.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
