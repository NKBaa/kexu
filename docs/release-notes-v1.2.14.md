# 课序 v1.2.14

修复课表顶部周次标题显示不全的问题。

## 更新内容

- 顶栏标题去掉「（本周）」后缀，只显示「第 N 周」，避免被右侧按钮挤成省略号；
- 标题使用 `FittedBox` 自动缩放，窄屏/大字体下也不会截断；
- 日期仍显示在标题下方 `yyyy/M/d`；
- 点标题选周次、左右滑动、撤销/重做与更多菜单保持不变；
- 测试保持 667 用例（661 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.14+70（Android versionCode 70）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.14-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.14.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
