# 课序 v1.2.12

撤销/重做增加操作细则：按钮提示与结果提示会说明具体改了什么。

## 更新内容

- 历史记录新增「修改说明」，自动比较前后课表生成：
  - 新增课程：`添加课程「高等数学」`
  - 删除课程：`删除课程「高等数学」、「数据结构」`
  - 修改课程：`修改课程「高等数学」`
  - 学期/作息变化：`修改学期设置` / `修改作息时间`
- 顶栏撤销/重做按钮 tooltip 显示细则，例如：
  - `撤销：删除课程「高等数学」、「数据结构」`
  - `重做：删除课程「高等数学」、「数据结构」`
- 执行撤销/重做后，提示条也会显示具体说明。
- 兼容旧历史文件：没有说明的旧记录会回退为通用提示。
- 测试保持 667 用例（661 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.12+68（Android versionCode 68）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.12-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.12.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
