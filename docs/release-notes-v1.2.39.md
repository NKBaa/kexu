# 课序 v1.2.39

修正首次使用向导里指向错误设置页的步骤。

## 更新内容

- **第 1 步改为「设置学期与作息」**：
  - 先展示当前学期（名称、起始日、总周数），点「修改」打开「设置 → 学期与作息」；
  - 再选择学校导入作息模板，避免学期基准不对导致模板生效日期算错。
- **节假日步骤指向正确入口**：
  - 原「添加 / 管理节假日」错误地打开了「上课提醒」页；
  - 现在打开「设置 → 学期与作息」，页面底部就是「节假日」卡片；
  - 页面明确写出入口位置，AI 设置节假日仍可直接使用。
- **AI 步骤文案更新**：语言模型说明改为「改课表 / 加日程」，与统一 AI 窗口一致；
- 首次向导的添加课程说明同步为「AI 助手（改课表 / 加日程）」；
- 测试 702 用例（696 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.39+95（Android versionCode 95）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.39-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.39.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
