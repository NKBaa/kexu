# 课序 v1.2.22

新增课表拖拽选节次，以及课表编辑/新增的初次使用教程。

## 更新内容

- **长按空白处拖拽新增**：
  - 长按课表空白处会开始选择节次；
  - 继续上下拖动可一次选中连续几节；
  - 松开后按所选星期与节次范围打开新增课程页；
  - 选择过程中实时高亮并显示「第 X-Y 节」。
- **课表初次使用教程**：
  - 第一次进入课表自动展示三步教程：长按新增、长按/拖动编辑、撤销与更多；
  - 「更多 → 使用教程」可随时重新打开；
  - 教程完成后不再自动弹出。
- **新增课程页初次提示**：
  - 第一次打开新增课程页显示一条简短说明；
  - 说明可添加多个上课时段、独立设置周次；
  - 关闭后不再重复显示。
- 测试 688 用例（682 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.22+78（Android versionCode 78）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.22-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.22.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
