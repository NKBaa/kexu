# 课序 v1.2.28

新增「日程」页签，并把批量修改收进「更多」菜单。

## 更新内容

- 底部导航改为：**课表 / 日程 / 设置**；
- 新增「日程」页：
  - 按天列出当前教学周的课程、时间、教师与地点；
  - 支持上一周 / 下一周 / 回到本周；
  - 节假日显示放假，不排课；
  - 点击课程可进入编辑页。
- 「批量修改」从底部页签移到课表顶栏「更多 → 批量修改」；
- 其他入口保持不变：添加课程、分享、导入导出、重启教程仍在「更多」；
- 测试 692 用例（686 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.28+84（Android versionCode 84）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.28-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.28.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
