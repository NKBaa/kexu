# 课序 v1.1.31

新增「作息模板」：模板托管在 GitHub，按学校分组选择。

## 更新内容

- 在 **设置 → 学期与作息 → 作息方案** 下新增「从 GitHub 模板导入」入口。
- 模板目录托管在仓库的 `templates/bell_schedules.json`：
  - 按 **学校** 分组，显示学校说明与每套模板的节数、起止时间；
  - 点击模板可预览每节时间，再点「使用此模板」新增一套作息；
  - 应用后模板优先生效，原有带生效日期的方案优先级不变，原默认作息保留为兜底。
- 模板拉取沿用「检查更新」里的仓库与镜像配置，支持 GitHub 直连和国内镜像回退，
  返回错误时可重试并看到可读原因。
- 仓库新增 `templates/README.md`，说明学校模板的 JSON 格式与提交方式。
- 新增模板解析、GitHub 拉取/镜像回退与模板页测试；测试 577 用例
  （571 通过 / 6 默认跳过），`flutter analyze` 0 issue。
- 版本 1.1.31+33（Android versionCode 33）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.31-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.31.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
