# 课序 v1.2.32

交互教程在首次向导完成后自动启动，直接覆盖真实界面。

## 更新内容

- 首次完成「使用向导」后，自动进入交互教程；
- 交互教程高亮真实控件：
  - 顶栏周次：点它切换周次；
  - 「更多」：添加课程、批量修改、分享、导入导出、交互教程；
  - AI 悬浮按钮：一句话改课表、发图片；
  - 课表网格：长按空白新增、拖动选节次、长按课程编辑。
- 教程层可点真实按钮，也可用「上一步 / 下一步」；
- 之后仍可从课表「更多 → 交互教程」随时重看；
- 测试 697 用例（691 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.32+88（Android versionCode 88）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.32-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.32.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
