# 课序 v1.1.26

为划动切换周次加上轻量动效。

## 更新内容

- 课表切周时增加 **220ms 横向滑入 + 淡入** 动效：
  - 向左滑 / 下一周：新一周从右侧滑入；
  - 向右滑 / 上一周：新一周从左侧滑入；
  - 旧一周反向滑出并淡出。
- 顶栏「上一周 / 下一周」按钮切周也会触发同样的动效。
- 动效不改变原有手势：拖动柄跨天、卡片点击/长按、窄屏横向滚动均不受影响。
- 版本 1.1.26+28（Android versionCode 28）。
- 测试保持 567 个用例（561 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.26-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.26.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
