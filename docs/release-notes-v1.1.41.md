# 课序 v1.1.41

新增首次使用向导，三步完成上手。

## 更新内容

- 首次启动进入三步使用向导：
  1. **选择学校设置作息**：从 GitHub 学校模板中选择学校，一键导入该校全部作息；
  2. **配置大模型 API**：查看视觉/语言模型状态，可打开配置页，也可跳过；
  3. **选择添加课程方式**：查看图片转课表、一句话改课表、手动添加三种方式说明。
- 顶部「跳过」可随时完成向导；每一步也支持跳过。
- 向导完成状态写入 `settings.json` 的 `onboardingCompleted`，之后不再自动弹出。
- 新增向导测试；测试 583 用例（577 通过 / 6 默认跳过），`flutter analyze` 0 issue。
- 版本 1.1.41+43（Android versionCode 43）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.41-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.41.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
