# 课序 v1.1.7

本次更新新增「修改历史与回退」：课表的最近 20 次修改都会留下快照，随时可以回退。

## 更新内容

### 修改历史与回退
- 每次修改课表 / 作息 / 学期，自动记录一份**修改前快照**到 `history.json`，
  最多保留最近 **20 次**；内容没变化的保存会自动去重，不会塞满历史。
- 课表顶栏新增「回退」按钮（撤销图标）：打开「修改历史」面板后：
  - 可一键「回退上一步」；
  - 也可在列表里选择任一历史版本「回退到此版本」；
  - 回退到旧版本后，比它更新的快照会自动丢弃。
- 同步、导入、AI 批量修改同样会记录；历史文件损坏或不可写不影响课表保存。
- 历史面板展示每条记录的时间、学期名、课程数与作息套数，方便辨认。

### 其他
- 版本 1.1.7+9（Android versionCode 9）。
- 测试增至 552 个用例（546 通过 / 6 默认跳过），新增历史仓储、控制器回退与顶栏按钮测试。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.7-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.7.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
