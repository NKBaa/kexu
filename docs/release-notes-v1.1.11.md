# 课序 v1.1.11

本次更新重新优化「学期与作息」页排版，解决窄屏下字段文字被截断、行内元素拥挤的问题。

## 更新内容

### 学期与作息页面排版
- 学期名称、第 1 周周一、总周数改为**纵向整行排列**，窄屏下不再出现：
  - 「2026-08-31 周一」被截断成「2026-08-1」；
  - 「常见 16~20 周」被截断成「常见 16~2…」。
- 常用周数 Chip 独立一行；「按今天定位」改为**独立浅色卡片**：
  标题 + 「今天是第 N 周」输入 + 定位按钮 + 今日日期说明，层级更清晰、不再挤成两行。
- 作息方案卡片头部改为两行摘要（「共 N 套作息」/「今天生效：X」），
  与右侧「新增方案」按钮顶部对齐，不再出现文字绕排卡在按钮中间。

### 其他
- 版本 1.1.11+13（Android versionCode 13）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.11-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.11.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
