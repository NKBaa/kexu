# 课序 v1.1.13

修复冲突课程仍然被挤成「竖条」的问题：冲突日整列按分栏数横向加宽，让并排课程保持接近普通列的宽度。

## 更新内容

### 冲突课程横向分栏（加宽）
- 同一天有冲突课程时，该列按最大分栏数**横向加宽**（2 门冲突 → 2 份宽度，3 门 → 3 份，最多 4 份），
  并排的每门课仍有接近普通单列的宽度，不再被压成一条只放得下一个字的竖条。
- 其它列按比例略窄，7 天仍一屏放下；无冲突时列宽与之前完全一致。
- 星期表头增加单行省略保护，列变窄时日期不会换行撑高表头。
- 冲突课程的警告描边、警告图标、点击详情、长按编辑、拖动调节次保持不变。

### 其他
- 版本 1.1.13+15（Android versionCode 15）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.13-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.13.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
