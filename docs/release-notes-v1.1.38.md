# 课序 v1.1.38

大模型配置采用「提供商」列表重写。

## 更新内容

- 大模型配置首页改为**提供商卡片列表**：
  - 视觉模型：用于图片转课表；
  - 语言模型：用于一句话改课表；
  - 卡片显示配置状态、当前模型，并提供「分享 / 模型 / 配置」操作。
- 点击「配置」进入独立模型详情页，保留原有：
  - 服务商预设；
  - baseUrl / API Key / 模型名；
  - 获取模型列表、测试连接；
  - 温度与超时设置。
- 「分享」会把当前模型配置 JSON 复制到剪贴板。
- 新增提供商列表页面测试；测试 581 用例（575 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.38+40（Android versionCode 40）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.38-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.38.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
