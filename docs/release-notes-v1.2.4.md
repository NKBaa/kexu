# 课序 v1.2.4

模型能力名单改为自动从 GitHub 拉取，更新模型/能力不用发新版。

## 更新内容

- 新增 `templates/ai_models.json` 远程模型名单；
- 打开视觉/语言模型详情页时自动拉取名单：
  - 仓库与镜像沿用「设置 → 检查更新」配置；
  - 成功后缓存到本地，离线时优先用缓存；
  - 网络失败且无缓存时回退 App 内置的 30+ 模型名单；
- 模型详情页显示名单状态：
  - `GitHub 模型名单 · N 个 · 更新日期`
  - 或「本地缓存模型名单」「内置模型名单」及失败原因；
  - 右侧刷新按钮可立即重新拉取；
- 保留原有能力筛选、服务商筛选、搜索、免费/推荐筛选；
- 新增模型名单解析、GitHub 拉取、缓存读写测试；
- 测试 661 用例（655 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.4+60（Android versionCode 60）。

## 维护方式

修改仓库 `templates/ai_models.json` 并提交到 `main`，App 在模型详情页打开或点刷新即可看到新名单，不需要重新发布安装包。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.4-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.4.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
