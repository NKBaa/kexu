# 课序 v1.2.42

全部 UI 统一为 ColorOS 16 设计语言。

## 更新内容

- **全局主题重写**：
  - 深色：近黑背景、`#141416` 卡片、ColorOS 蓝强调；
  - 浅色：浅灰背景、白色卡片、同一套蓝色强调；
  - 卡片 24px 大圆角、按钮/输入框胶囊化、无边框输入框；
  - 页面切换改为淡入过渡，移除旧 iOS / 牛皮纸配色。
- **底部导航改为浮动胶囊 Dock**：圆角 32、阴影浮层、蓝色选中态；
  宽屏仍使用侧边导航栏。
- **课表页**：课程卡片圆角与全局主题统一，顶栏、按钮、弹窗跟随 ColorOS 主题。
- **设置 / 批量修改 / 课程编辑 / AI 助手 / 首次向导 / 使用教程**：
  统一继承新的卡片、按钮、输入框、对话框、SnackBar 与开关样式。
- **日程页**：保留上一版的 ColorOS 深色/浅色配色，并与全局主题对齐。
- **日历抽屉可跟手划动**：上下拖动月历时高度实时跟随手指，松手按速度/位置吸附到
  整月或单周；点箭头也能切换。
- 主题中心默认主题更名为「ColorOS（默认）」。
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.42+98（Android versionCode 98）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.42-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.42.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
