# 课序 v1.2.17

统一「更多」菜单的界面风格。

## 更新内容

- 「更多」从默认弹出菜单改为与分享、课程详情一致的底部面板：
  - 带拖动条和「更多」标题；
  - 使用统一的圆角、留白与图标颜色；
  - 添加课程、分享课表、导入/导出数据、上一周/下一周分组排列；
- 不可用的上一周/下一周仍保持禁用态；
- 顶部「回到本周」、撤销/重做行为不变；
- 测试保持 678 用例（672 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.17+73（Android versionCode 73）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.17-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.17.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
