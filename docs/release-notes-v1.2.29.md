# 课序 v1.2.29

删除「上一周 / 下一周」入口，周次切换统一用标题选择。

## 更新内容

- 课表顶栏「更多」里删除「上一周 / 下一周」两项；
- 日程页删除上一周 / 下一周按钮：
  - 点「第 N 周」标题打开周次选择器；
  - 右上角保留「回到本周」；
- 课表仍可左右滑动切周、点标题选周；
- 测试 692 用例（686 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.29+85（Android versionCode 85）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.29-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.29.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
