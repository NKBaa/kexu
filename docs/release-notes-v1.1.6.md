# 课序 v1.1.6

本次更新优化「学期与作息」页：两个并排输入框高度对齐，并新增「按今天第几周反推学期范围」。

## 更新内容

### 学期设置
- **「第 1 周周一」与「总周数」高度对齐**：两边统一用输入框（日期框只读、点击弹日历），
  并各自带一行辅助说明，手机上不再出现一高一矮 / 日期换行顶高的问题。
- **新增「按今天定位」**：只记得「今天是第几周」时，填 N → 点「定位」，
  App 自动反推第 1 周周一（今天 − `(N−1)×7` 天所在周的周一），
  并在提示条里显示结果；非法周次会给出中文提示，不会改动学期。
- 学期摘要行继续显示「第 1 周周一 · 学期结束」，方便确认范围。

### 其他
- 版本 1.1.6+8（Android versionCode 8）。
- 测试增至 543 个用例（537 通过 / 6 默认跳过），新增周次反推与表单高度对齐测试。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.6-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.6.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
