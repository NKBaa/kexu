# 课序 v1.1.32

界面采用 Material 3 Expressive 风格做整体视觉升级。

## 更新内容

- **暖白 + 黑字 + 深蓝强调**：浅色模式改为暖米白背景，深色模式保持同结构的低对比层级。
- **更柔和的圆角**：卡片/弹窗统一为 24px 大圆角，输入框、按钮、筛选控件保持胶囊形。
- **课程配色换成低饱和粉彩**：保留每门课的区分度，同时减少高饱和色块在暖白背景上的刺眼感。
- **设置中心图标卡片化**：每个设置分类使用圆角浅色图标底，更接近现代 Material 3 Expressive 设置列表。
- **导航与顶栏**：底部导航/侧边导航、顶栏标题、按钮和 SnackBar 统一使用新主题。
- 版本 1.1.32+34（Android versionCode 34）。
- 测试保持 577 用例（571 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.32-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.32.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
