# 课序 v1.1.17

移除「批量操作」页顶部标题栏，让页面直接进入搜索与课程列表。

## 更新内容

- 删除批量操作页的 AppBar（原「批量操作」标题和右上角清空选择按钮）：
  - 清空选择在筛选栏的「全选 / 反选」旁已有入口，不丢失功能；
  - 批量处理中的加载状态改为页面顶部细进度条；
  - 页面使用 `SafeArea`，不会被手机状态栏遮挡。
- 版本 1.1.17+19（Android versionCode 19）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.17-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.17.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
