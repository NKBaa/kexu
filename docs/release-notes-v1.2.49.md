# 课序 v1.2.49

取消课程卡片的独立拖动按钮，改为短按编辑、长按整卡拖动。

## 更新内容

- 短按课程卡片直接进入课程编辑，长按整张卡片约 500 毫秒后进入拖动。
- 按住时整卡轻微缩小，并显示逐渐走满的进度圆环和高亮描边。
- 长按触发时提供明显的触觉反馈；拖动中显示放大浮层和“拖动中”标识。
- 保留目标节次预览、跨星期移动和课程跨节数。
- 快速滑动或未按满时长就移动不会误改课程。
- 更新新手引导和拖动提示，并补充短按编辑、按压反馈、长按拖动和跨天拖动测试。

版本：1.2.49+105（Android versionCode 105）。

## 签名说明

本次更换了 Android 发布签名。由于旧签名密钥无法恢复，安装 v1.2.49 前需要卸载旧版本；从本版本开始，后续 Android 更新恢复为可覆盖安装。

## 构建产物

- Android：`kexu-v1.2.49.apk`，使用新的固定发布签名。
- Windows：本版本不构建。
