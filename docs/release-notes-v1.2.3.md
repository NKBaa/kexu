# 课序 v1.2.3

新增内置模型能力目录，帮助用户按能力选模型。

## 更新内容

- 视觉/语言模型详情页新增「按能力选内置模型」：
  - 内置 30+ 个常见模型，覆盖硅基流动、智谱 GLM、通义千问、OpenAI、
    DeepSeek、Moonshot、CottonAPI；
  - 每个模型标注：图片 / 文本能力、是否免费、上下文长度、适合场景；
  - 支持按当前任务过滤（视觉页只显示能看图的模型）、服务商过滤、搜索、
    只看免费、只看课表推荐；
  - 选中其他服务商的模型时，自动切换对应 API 地址，并提醒确认 API Key。
- 模型输入框下方显示当前模型的能力标签与选型建议；
- 从服务端获取的模型列表中，命中内置目录的模型也会显示能力标签；
- 内置目录是选型参考，模型名/能力以服务商实际可用模型为准，可点
  「获取模型列表」重新选择。
- 新增模型目录与选择器测试；测试 655 用例（649 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.2.3+59（Android versionCode 59）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.3-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.3.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
