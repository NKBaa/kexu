# 课序 v1.1.44

下方提示信息条改为紧凑样式，减少对课表的遮挡。

## 更新内容

- 统一提示条样式：
  - 最大宽度 300，居中悬浮；
  - 圆角胶囊外观，带状态图标；
  - 字号 12.5，最多两行并自动省略；
  - 2 秒后自动消失。
- 拖动课程、课程更新、AI 执行结果等提示统一使用该样式。
- 版本 1.1.44+46（Android versionCode 46）。
- 测试保持 584 用例（578 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.44-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.44.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
