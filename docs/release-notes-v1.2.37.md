# 课序 v1.2.37

重写「使用教程」：从首次配置向导中拆出独立的 6 节功能教程。

## 更新内容

- **使用教程独立成 6 节**，不再复用首次向导的配置步骤：
  1. 认识课表：周次切换、回到本周、看懂课程块；
  2. 添加课程：长按空白格、菜单添加、图片 / AI；
  3. 编辑与调整：长按编辑、拖动换时间、多时段、撤销重做；
  4. 日程与提醒：月历、新建日程、AI 加日程、上课提醒；
  5. AI 助手：同一个窗口改课表 / 加日程、发图片、先预览再应用；
  6. 设置与数据：学期作息、主题、数据备份、检查更新。
- 每节包含「入口」标签、操作说明和小提示，内容与当前界面一致；
- **宽屏（Windows / 平板）左侧显示教程目录**，可直接跳到任意一节；
- 手机端使用分节进度条与「上一节 / 下一节」导航；
- 首次使用向导仍保留 5 步配置流程，并修正了「添加课程」入口说明；
- 测试 701 用例（695 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.37+93（Android versionCode 93）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.37-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.37.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
