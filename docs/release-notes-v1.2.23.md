# 课序 v1.2.23

把节假日管理移到「学期与作息」里。

## 更新内容

- `设置 → 学期与作息` 新增「节假日」卡片：
  - 添加 / 删除节假日；
  - AI 设置节假日；
  - 放假当天不排上课提醒；
- 原「节假日与提醒」入口改名为「上课提醒」：
  - 只保留提醒开关、提前分钟、通知样式与权限；
  - 节假日管理统一在「学期与作息」里；
- 测试 689 用例（683 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.23+79（Android versionCode 79）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.23-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.23.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
