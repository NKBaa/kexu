# 课序 v1.1.47

提示信息条移到星期表头下方。

## 更新内容

- 所有轻量提示（拖动课程、课程更新、AI 执行结果等）改为显示在**顶部星期表头下方**：
  - 位于 AppBar 下方、周一~周日表头之后；
  - 居中显示，最大宽度自适应屏幕；
  - 不再盖住课程卡片或底部 AI 按钮；
  - 2 秒后自动消失。
- 版本 1.1.47+49（Android versionCode 49）。
- 测试保持 585 用例（579 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.47-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.47.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
