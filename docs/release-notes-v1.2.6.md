# 课序 v1.2.6

重做 Android 桌面小组件布局，解决内容太简单、下方大片空白的问题。

## 更新内容

- **自适应高度**：课程卡片按小组件可用高度自动撑满，只有 1~2 门课时不再在下方留空白；
  默认 4x4 尺寸显示 3 门课，拉高到 4x5 显示 4 门；
- **信息层级**：顶部标题 + 课程数/教学周 + 日期/星期，底部固定「更新于」；
- **课程卡片**：每门课独立圆角卡片，左侧色条区分状态，时间/课程名/教室分层显示；
- **状态标记**：
  - 正在上的课：蓝色高亮卡片 + 「进行中」标记；
  - 下一节课：蓝色色条 + 「下一节」标记；
- **空状态/节假日**：今天没课时居中显示「今天没有课」；节假日显示节日名称与「好好休息」；
- 快照过期时仍居中提示「打开课序查看今日课程」；
- 测试保持 661 用例（655 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.6+62（Android versionCode 62）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.6-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.6.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
