# 课序 v1.1.48

图片重复导入时自动识别已导入课程，可选择覆盖或同时存在。

## 更新内容

- 识别结果列表中，与现有课表重名的课程会显示「已导入」标记；
- 点击「导入」时，如有重名课程会弹出确认：
  - **同时存在**：保留原课程，再把新识别的课程追加一份；
  - **覆盖已有**：删除原同名课程，用本次识别结果替换；
  - **取消**：不导入。
- 课程名匹配忽略首尾空格、大小写和中间空白；
- 覆盖/同时存在都会记录一次课表修改历史，可回退。
- 新增重名识别单元测试；测试 587 用例（581 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.48+50（Android versionCode 50）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.48-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.48.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
