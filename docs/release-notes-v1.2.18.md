# 课序 v1.2.18

重写 AI 助手界面，加入按钮渐变扩散特效、毛玻璃质感和图片对话。

## 更新内容

- **AI 按钮特效**：点击右下角「AI」后，以按钮中心为圆心，渐变圆形扩散到全屏，
  再进入 AI 助手；
- **AI 界面重写**：
  - 渐变背景 + 毛玻璃气泡、输入框、方案卡片与顶部信息条；
  - 类似手机助手的对话布局，空状态提供可直接点的示例；
  - 顶部显示「现在」的日期、星期与教学周；
- **AI 支持图片**：
  - 左下角图片按钮可直接附课表截图（最多 4 张），发送后显示在用户气泡里；
  - 有语言模型时，图片直接交给语言模型；
  - 没有语言模型时，先用识图模型把图片转述成文字，再据此生成改课表方案；
  - 两者都没配置时给出明确提示；
- 多轮对话、反问候选、方案勾选、执行报告与撤销/重做保持不变；
- 测试 684 用例（678 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.18+74（Android versionCode 74）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.18-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.18.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
