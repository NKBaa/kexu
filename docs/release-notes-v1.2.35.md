# 课序 v1.2.35

时间设置与整体界面改为苹果 iOS 风格，并清理重复组件。

## 更新内容

- **所有日期/时间设置改用苹果滚轮选择器**：
  - 日程开始/结束时间；
  - 作息方案每节开始/结束时间；
  - 学期第 1 周日期；
  - 节假日日期；
  - 作息方案生效日期。
- **整体 UI 改为 iOS 风格**：
  - 浅灰分组背景、白色圆角卡片、细分割线；
  - 系统蓝强调色，iOS 绿色开关；
  - Cupertino 页面转场、无 Material 水波纹；
  - 底部导航改为 iOS 标签栏观感，选中态使用系统蓝。
- **删除重复组件**：
  - 日程日期标题旁重复的「添加」按钮，只保留右下角新建按钮；
  - 日程 AI 与课表 AI 已合并为同一个 AI 窗口。
- 测试 700 用例（694 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.35+91（Android versionCode 91）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.35-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.35.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
