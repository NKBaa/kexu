# 课序 v1.2.5

把硅基流动提升为与 CottonAPI 同级的推荐服务商。

## 更新内容

- 「大模型配置」顶部卡片标题改为「**推荐使用硅基流动 SiliconFlow**」；
- 服务商预设名称改为「**硅基流动 SiliconFlow（推荐）**」；
- 首次使用向导的 AI 步骤文案改为「推荐使用硅基流动」；
- CottonAPI 仍保留推荐入口，两个服务商都可以直接选用；
- 注册/登录、充值、API Key、使用指南入口保持不变；
- 测试保持 661 用例（655 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.5+61（Android versionCode 61）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.5-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.5.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
