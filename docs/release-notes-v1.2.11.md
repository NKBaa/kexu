# 课序 v1.2.11

移除课表顶栏的「学期结束」标记。

## 更新内容

- 顶栏大号周次只显示「第 N 周」；当前周显示「第 N 周（本周）」；
- 不再显示「（学期结束）」；
- 其余顶栏布局、周次选择、撤销/重做与更多菜单保持不变；
- 测试保持 667 用例（661 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.11+67（Android versionCode 67）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.11-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.11.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
