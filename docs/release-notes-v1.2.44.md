# 课序 v1.2.44

修正日程页的滚动结构：标题栏固定，滚动日程区域时日历收缩。

## 更新内容

- **顶部标题栏固定**：年月、周次、AI 与更多按钮不再随页面滚动；
- **日历固定**：月历本身不参与页面滚动；
- **滚动日程区域收缩日历**：
  - 在下方「日程显示」区域向下滚动时，日历自动收缩成单周；
  - 回到日程列表顶部时，日历自动展开成整月；
  - 仍可拖动日历底部把手或点把手手动收缩/展开。
- 单周视图保留相对天数、公历、农历与「今日安排」。
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.44+100（Android versionCode 100）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.44-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.44.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
