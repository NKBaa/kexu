# 课序 v1.2.45

修复日程日历收缩后回弹的问题。

## 更新内容

- 日历只在**用户手指拖动日程列表**时收缩/展开，不再响应惯性滚动与边界回弹；
- 自动收缩后，只有回到列表顶部并继续下拉才展开，避免松手后立刻弹回；
- 手动拖动把手或点按把手切换时，不会被日程滚动状态覆盖；
- 顶部标题栏与日历保持固定，滚动日程区域仍会自动收缩日历；
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.45+101（Android versionCode 101）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.45-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.45.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
