# 课序 v1.1.51

图片转课表支持单日课表：图片带日期时只导入该日期当天的课程。

## 更新内容

- 视觉提示词新增顶层 `date` 字段：
  - 图片是单日课表（如顶部有 `2026-11-02`、`11月2日`、今日课表）时，模型返回该日期；
  - 整周课表即使表头有日期，也不会被当作单日课表。
- 识别后按图片日期自动处理：
  - 只保留该日期对应星期的课程；
  - 周次限定为该日期所在教学周；
  - 其他日期的课程自动忽略，并给出提示；
  - 日期不在当前学期时保留原周次并提醒核对。
- 支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY年M月D日`、`MM-DD`、`M月D日` 等日期格式。
- 使用说明中补充单日课表行为。
- 新增日期解析与过滤测试；测试 592 用例（586 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.51+53（Android versionCode 53）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.51-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.51.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
