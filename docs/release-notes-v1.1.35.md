# 课序 v1.1.35

作息模板改为「先学校、后详情」，并支持整套导入与搜索。

## 更新内容

- 模板页**先只显示学校列表**；点击学校后进入详情页，查看每套作息的逐节时间。
- 学校详情页新增「全部导入（N 套）」：
  - 分季节作息可一次全部导入，而不是春季、秋季分两次；
  - 模板支持可选 `dateRange`（如 `05-01 ~ 10-01`），导入时按当前学期自动换算年份；
  - 带日期的方案保持日期优先级，常驻模板仍作为兜底。
- 模板页新增**搜索按钮**，可按学校名或作息模板名搜索。
- 高校作息模板补充春季/秋季日期范围。
- `templates/README.md` 增加 `dateRange` 格式说明。
- 新增学校详情/日期范围测试；测试 579 用例（573 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.35+37（Android versionCode 37）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.35-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.35.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
