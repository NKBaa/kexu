# 课序 v1.2.31

教程改为覆盖在真实界面上的交互式引导，不再只是静态步骤说明。

## 更新内容

- 课表「更多 → 交互教程」启动真实界面引导：
  - 高亮顶栏周次：点它可以切换周次；
  - 高亮「更多」：添加课程、批量修改、分享、导入导出都在这里；
  - 高亮 AI 悬浮按钮：一句话改课表、发图片；
  - 高亮课表网格：长按空白新增、拖动选节次、长按课程编辑。
- 引导层会直接套在真实控件上，可以点真实按钮，也可以点「上一步 / 下一步」；
- 首次启动的「使用向导」继续负责学校作息、大模型、节假日等初始化设置；
- 新增 `showcaseview` 依赖实现聚光灯式引导；
- 测试 697 用例（691 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.31+87（Android versionCode 87）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.31-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.31.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
