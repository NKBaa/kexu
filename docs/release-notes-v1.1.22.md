# 课序 v1.1.22

支持在课表上左右划动切换周次。

## 更新内容

- 课表区域支持**左右划动切换周次**：
  - 向左滑 → 下一周；向右滑 → 上一周；
  - 划动速度过小（<220）不触发，避免误切；
  - 窄屏需要横向滚动查看课表时，优先保证课表横向滚动，不抢划动手势。
- 拖动课程柄横向跨天时不会误触发周次切换；拖动/点击/长按行为保持不变。
- 新增测试：划动切周、拖动柄跨天不切周；测试总数 566（560 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.22+24（Android versionCode 24）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.22-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.22.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
