# 课序 v1.2.20

修复「今天」高亮跨周重复的问题。

## 更新内容

- 之前只按星期几判断「今天」，导致切到其它周时，同一星期几也会被高亮；
- 现在会同时校验「今天」是否落在当前显示的教学周：
  - 只有当前显示周确实是今天所在周，才高亮表头与当天列；
  - 切到上一周/下一周后，不再错误高亮同一星期几；
- 新增回归测试覆盖「第 1 周今天 / 第 2 周不高亮」；
- 测试 686 用例（680 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.20+76（Android versionCode 76）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.20-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.20.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
