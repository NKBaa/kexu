# 课序 v1.2.40

默认主题改为「黑灰 + 牛皮纸黄 + 白」。

## 更新内容

- **浅色默认主题**：
  - 牛皮纸黄背景；
  - 白色圆角卡片与输入框；
  - 黑灰文字与黑灰强调色；
  - 分割线、导航栏、开关同步换成牛皮纸 / 黑灰色系。
- **深色默认主题**：
  - 黑灰背景与卡片；
  - 牛皮纸黄强调色；
  - 暖白文字。
- 主题中心的「默认」内置主题同步改名「黑灰牛皮纸（默认）」，
  预览与切换后使用完全相同的色板。
- 移除原先的 iOS 蓝色强调色与绿色开关，避免和牛皮纸配色冲突。
- 测试 702 用例（696 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.40+96（Android versionCode 96）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.40-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.40.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
