# 课序 v1.2.15

调整课表顶栏：回到本周放顶栏，添加课程收进更多菜单。

## 更新内容

- 顶栏右侧改为：**回到本周** / 撤销 / 重做 / 更多；
- 「添加课程」移入「更多」菜单，减少顶栏占用；
- 「更多」菜单顺序：添加课程、分享课表、导入/导出数据、
  上一周 / 下一周；
- 当前就在本周时「回到本周」按钮自动禁用；
- 测试保持 667 用例（661 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.15+71（Android versionCode 71）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.15-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.15.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
