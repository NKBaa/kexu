# 课序 v1.1.24

作息方案新增「午休 / 晚休时间」设置。

## 更新内容

- 每套作息方案新增可选的**午休**（默认提示 11:40-14:00）与**晚休**（默认提示 17:40-19:00）
  开始/结束时间输入。
- 休息时间只用于在作息摘要中展示，不影响每节课的上下课时间与节次计算。
- 保存时校验：开始和结束要么都留空、要么都填写；格式必须为 HH:mm，且结束需晚于开始。
- 作息方案列表摘要会追加显示，如「午休 11:40-14:00 · 晚休 17:40-19:00」。
- 数据写入 `BellSchedule` JSON（`lunchBreak` / `dinnerBreak`），旧数据没有字段时自动为 null，兼容旧版本。
- 新增模型往返/旧数据兼容测试与设置页保存测试；测试 568 用例（562 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.24+26（Android versionCode 26）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.24-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.24.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
