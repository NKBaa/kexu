# 课序 v1.1.53

批量操作页的星期/周次筛选合并为一个筛选按钮。

## 更新内容

- 搜索框右侧只保留一个「筛选」按钮：
  - 未筛选时显示「筛选」；
  - 已筛选时直接显示当前条件，如「周三 · 1-8周」。
- 点击后打开筛选面板：
  - 星期：全部星期 / 周一~周日；
  - 周次：全部周次或自定义周次；
  - 面板右上角提供「取消筛选」；
  - 底部「完成」关闭面板。
- 窄屏下搜索框与筛选按钮保持同一行，不溢出。
- 版本 1.1.53+55（Android versionCode 55）。
- 测试保持 593 用例（587 通过 / 6 默认跳过），`flutter analyze` 0 issue。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.53-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.53.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
