# 课序 v1.2.19

支持长按课表空白处，在点击位置新增课程。

## 更新内容

- 长按课表空白单元格：
  - 自动按落点换算出星期与节次；
  - 打开新增课程页，星期与节次已预填；
  - 课程默认覆盖整个学期，可再调整周次/跨节；
- 长按课程卡片仍是编辑课程；拖动课程卡片仍可调整星期与节次；
- 测试 685 用例（679 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.19+75（Android versionCode 75）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.19-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.19.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
