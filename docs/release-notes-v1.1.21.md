# 课序 v1.1.21

改进课程拖动体验：拖动时显示目标时间段，并允许在同一周内自由拖到任意星期。

## 更新内容

- **拖动预览**：拖动课程经过某一列时，该列会实时画出目标时间段（半透明高亮 + 边框），
  并显示「第 X-Y 节」标签，松手前就能确认会落到哪里。
- **同一周内自由拖拽**：不再限制只能拖回原星期，可拖到周一到周日任意一列；
  跨天时同步修改该时段的 `dayOfWeek`，纵向落点决定起止节次，跨节数保持不变。
- 完成拖动后的提示会带上星期，如「已把「高等数学」调整到周三 第5-6节」。
- 拖动仍只从卡片右下角拖动柄发起，拖正文不会误触。
- 新增测试：跨天拖动会带上目标星期、拖动过程中显示「第5-6节」预览；
  测试总数 564（558 通过 / 6 默认跳过），`flutter analyze` 0 issue。
- 版本 1.1.21+23（Android versionCode 23）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.21-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.21.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
