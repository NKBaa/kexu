# 课序 v1.2.41

日程页按 ColorOS 16 设计语言重写，月历支持滑动与收缩。

## 更新内容

- **ColorOS 16 风格日程页**：
  - 近黑背景、24px 大圆角卡片、ColorOS 蓝强调色；
  - 顶部大号年月标题 + 当前教学周，右侧 AI 与更多菜单；
  - 日期显示农历 / 节气 / 节日，有日程的日期显示蓝点；
  - 选中日期显示相对天数、农历与当天日程。
- **可收缩月历**：
  - 左右滑动切换月份；
  - 上下拖动月历，或点日历下方箭头，在「整月」和「单周」之间收缩；
  - 收缩后仍可左右滑动切月。
- **重复日程检测**：发现重复日程时显示提示条，可一键合并。
- **日程编辑器重写**：
  - 取消 / 新建 / 完成顶栏；
  - 大标题输入卡、全天开关、日期与起止时间、备注；
  - 深色/浅色自适应，圆角与强调色与日程页一致。
- 新增农历依赖 `lunar`，月历显示农历、节气与节日；
- 测试 703 用例（697 通过 / 6 默认跳过），`dart analyze lib test` 0 issue；
- 版本 1.2.41+97（Android versionCode 97）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.41-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.41.apk` 传到手机安装（固定发布签名）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
