# 课序 v1.1.52

更新完成后自动清理旧安装包。

## 更新内容

- App 启动时自动清理已经安装过的旧安装包：
  - 只删除文件名版本号 **小于等于当前版本** 的 `.apk` / `.exe` / `.zip` / `.msi`；
  - 刚下载、还没安装的新版本安装包会保留，避免重启后又要重新下载；
  - 同时清理中断下载留下的 `.part` 临时文件。
- 清理失败不会影响启动，文件被占用时下次启动会再试。
- 新增安装包清理测试；测试 593 用例（587 通过 / 6 默认跳过），
  `flutter analyze` 0 issue。
- 版本 1.1.52+54（Android versionCode 54）。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.52-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.52.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
