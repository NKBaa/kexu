# 课序 v1.2.47

修复日历拖动滞后、跳动，以及日程少时无法收起的问题。

## 更新内容

- 日历和日程使用同一个滚动容器，顶部年月标题始终固定。
- 日历高度直接随滚动距离变化，移除逐帧追赶手指的高度动画和滚动监听反馈。
- 空日程、只有一条日程时仍保留完整收缩距离，可以收起为单周。
- 选中日期所在周在收缩过程中连续移到顶部，不再突然替换月历。
- 点日历把手可平滑切换整月/单周，左右滑动切月保持可用。
- 回归测试覆盖 0 / 1 / 8 条日程、按住停留、反向拖动、固定标题和月份切换。

版本：1.2.47+103（Android versionCode 103）。

## 下载与安装

- Android：下载 `kexu-v1.2.47.apk`，使用与 v1.2.36 起相同的固定发布签名。
- Windows：下载 `kexu-v1.2.47-windows.zip`，解压后运行 `course_timetable.exe`。

## 应用内更新

在「设置 → 检查更新」获取本版本。
