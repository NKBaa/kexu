# 课序 v1.1.19

修复课程拖动容易误触的问题：改为从卡片右下角的专用拖动柄发起拖动。

## 更新内容

- 课程卡片正文不再直接响应拖动，避免课表滚动 / 点击时误触调整节次。
- 卡片右下角新增半透明「拖动柄」（小圆点图标）：
  - 按住拖动柄可调整课程节次，保持跨节数与星期不变；
  - 拖动时反馈卡片的左上角对齐原卡片，落点节次不会整体偏移；
  - 卡片正文的点击（查看详情）和长按（编辑课程）保持不变。
- 特别窄的卡片（宽度不足 30px）不显示拖动柄，仍可通过长按编辑修改节次。
- 版本 1.1.19+21（Android versionCode 21）。
- 测试保持 563 个用例（557 通过 / 6 默认跳过），`flutter analyze` 0 issue；
  新增回归断言：拖卡片正文不会触发拖动，拖拖动柄才会。

## 下载与安装

- **Windows**：下载 `kexu-v1.1.19-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.1.19.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
