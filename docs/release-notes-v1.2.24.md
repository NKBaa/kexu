# 课序 v1.2.24

把课表编辑教程合并进首次使用向导，并支持随时回看。

## 更新内容

- **统一教程**：首次使用向导扩展为 5 步：
  1. 学校作息；
  2. 大模型 API；
  3. 节假日；
  4. 添加课程方式；
  5. 课表编辑与新增（长按空白/拖拽选节次、长按课程编辑、拖动调整、撤销与重做）。
- **随时回看**：课表「更多 → 重启教程」会从第 1 步重新打开整份教程；
- 删除单独的课表教程弹层与新增课程页提示，避免多套教程重复；
- 测试 690 用例（684 通过 / 6 默认跳过），`flutter analyze` 0 issue；
- 版本 1.2.24+80（Android versionCode 80）。

## 下载与安装

- **Windows**：下载 `kexu-v1.2.24-windows.zip`，解压后双击 `course_timetable.exe`（免安装）。
- **Android**：下载 `kexu-v1.2.24.apk` 传到手机安装（debug 签名，需允许安装未知来源应用）。

## 应用内更新

默认仓库已写死为 `NKBaa/kexu`，旧版本在「设置 → 检查更新」里即可检测到本版本。
